

# 📊 Global Data Science Salary Dashboard (Power BI)

## 📌 Overview

This project presents an interactive **Global Data Science Salary Dashboard** built using **Power BI**. It analyzes salary trends across different roles, experience levels, locations, and work modes to uncover meaningful insights for data professionals and organizations.

---

## 🎯 Objectives

* Analyze salary distribution across data science roles
* Understand the impact of experience level on compensation
* Compare salaries across different countries
* Explore remote vs onsite work trends
* Identify top-paying roles and locations


## 📊 Key Metrics

* **Average Salary:** 113.09K
* **Maximum Salary:** 600K
* **Total Jobs Analyzed:** 597
* **Remote Work Percentage:** 63.32%

---

## 🔍 Key Insights

* 💼 Senior and executive roles earn significantly higher salaries
* 🌍 Remote jobs dominate the job market
* 📈 Salaries increase steadily with experience level
* 🏆 Certain countries and roles offer substantially higher pay
